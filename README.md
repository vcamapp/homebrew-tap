# Homebrew tap for VCam

Command line tools for [VCam](https://vcamapp.com/en/).

```sh
brew install vcamapp/tap/vcam-cli
```

| Formula | |
| --- | --- |
| `vcam-cli` | [VCam CLI](https://github.com/vcamapp/vcam-cli): controls VCam from your terminal, scripts, and AI agents |

The formulae are updated by the release workflows of each tool.
